# 🌿 EcoScan – AI-Powered Waste Analysis & Sustainability Website

**EcoScan** is an interactive web application built using Python and Streamlit that promotes environmental awareness and sustainable waste management. It uses Google's Gemini AI to analyze waste images, answer environmental questions, and provide recycling and disposal suggestions.

The platform also includes user registration, login, profile management, and a community review system.

## ✨ Features

### 🔍 1. AI Waste Image Analysis
- Upload images in JPG, JPEG, or PNG format.
- Identify visible objects and possible materials using Gemini AI.
- Classify waste into categories such as recyclable, organic, reusable, hazardous, electronic waste, or general waste.
- Receive recycling instructions and disposal suggestions.
- Explore reuse ideas and relevant environmental impacts.
- Download the generated analysis as a text file.

### 💬 2. EcoChat – AI Chatbot
- Ask questions about recycling and waste management.
- Learn about pollution, climate change, and composting.
- Receive practical sustainability suggestions.
- Maintain conversation history during the current session.
- Get responses generated by Google's Gemini API.

### 🔐 3. User Registration and Login
- Create an account using a name, email address, and password.
- Log in using registered credentials.
- Store account information in an SQLite database.
- Store passwords as salted PBKDF2 hashes rather than plain text.

### 👤 4. User Profile Management
- View account information.
- Update the display name.
- View the registered email and user ID.
- Log out of the application.

### ⭐ 5. Reviews and Feedback
- Submit a review and select a rating from one to five stars.
- View community feedback.
- Sort reviews by date or rating.
- Display the average rating and total review count.
- Store reviews in a CSV file.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before starting:

- Python 3.10 or later
- Visual Studio Code or another Python editor
- Internet connection
- Google Gemini API key

### Step 1: Clone the repository

If your project is hosted on GitHub:

```bash
git clone YOUR_REPOSITORY_URL
cd EcoScan
```

Alternatively, download the project and open the folder in VS Code.

### Step 2: Create a virtual environment

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Configure the Gemini API key

Obtain an API key from [Google AI Studio](https://aistudio.google.com/apikey).

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```

Replace the placeholder with your actual API key. Ensure that the selected Gemini model is available to your API account.

**Security:** Never commit your `.env` file or publish your API key.

### Step 5: Run the application

```bash
streamlit run app.py
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:8501
```

Register an account to access the EcoScan dashboard and its features.

1. Open the EcoScan website.
2. Register a new account or log in.

5. Use EcoChat to ask environmental questions.

7. Update account details in My Profile.

## ⚠️ Limitations

- AI image analysis may misidentify materials.
- Recycling facilities and rules vary by location.
- Gemini functionality requires a valid API key, internet access, and available API quota.
- Reviews use local CSV storage in the current implementation.
- Local files may not persist on some hosting platforms.
- The included authentication system is a prototype and requires additional security controls before public production use.

Always verify important disposal instructions with your local waste-management authority, especially for batteries, electronics, chemicals, and other hazardous waste.
